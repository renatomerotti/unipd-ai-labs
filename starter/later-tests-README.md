# Later tests — one at a time

Leave these here. Do **not** move them into `tests/` yourself.

Each phase's prompt asks the assistant to move its one test file across:

| File | Moved in by |
|---|---|
| `test_phase_2.py` | the Lab Step 2 prompt |
| `test_phase_3.py` | the Lab Step 3 prompt |
| `test_phase_4.py` | the Lab Step 4 prompt |
| `test_phase_5.py` | the Lab Step 5 prompt |

A test describes what a phase must do. Moving them all in now would show the
assistant work you have not reached, and it would build ahead of you.

Open one and read it whenever you like — that is not cheating, it is the
specification in executable form, and knowing what a phase has to satisfy before
you ask for it is the whole method.
