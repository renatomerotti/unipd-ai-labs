# Checkpoints — for recovery only

A working copy of the project at the end of Phases 1 and 2.

**Use one only if your own project is broken and you cannot fix it**, or your
daily request allowance has run out. Copy the folder's contents into your
`unipd-ai-lab` folder, replacing what is there. Then drag any test for a later
phase from `tests/` back into `later-tests/`, and carry on from the next phase.

You will have learned less than the person next to you. You will not be stuck,
and you will finish. That is a fine trade — take it rather than losing a session.

| Folder | Gets you to | Tests |
|---|---|---|
| `phase-1-complete/` | The application runs | `3 passed` |
| `phase-2-complete/` | The economy you inherited | `7 passed` |

Phases 3 and 4 are not here. Phase 3 contains the simulation itself, and copying
it would hand you the part of the lab that is actually worth doing. If you are
genuinely stuck there, ask.
